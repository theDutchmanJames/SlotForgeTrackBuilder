SLOTFORGE TRACK BUILDER v0.3.2

INSTALL
1. Extract the entire ZIP into a folder.
2. Run the installer for your system:
   Windows: Install Windows.cmd
   macOS:   Install macOS.command
   Linux:   sh "Install Linux.sh"
3. The app opens in your browser. Choose a track pack and start building.

Setup needs internet access the first time. It installs its own local helper;
you do not need to install Node.js or developer tools. Afterwards it works offline.
Windows setup is tested. Native macOS/Linux testing is still pending.

OPEN IT AGAIN
Windows: use the SlotForge Track Builder desktop shortcut.
macOS/Linux: open Start SlotForge in the installed folder. Setup prints its location.
Use the installed launcher for disk saving. Opening the HTML directly uses browser
storage instead; the footer clearly shows the current storage mode.

YOUR SAVED WORK
- Save to Library keeps a named track in your Track Library.
- Your current drawing and custom packs are saved locally as you work.
- Closing the browser or restarting your computer does not remove disk saves.
- App updates keep your data folder. Previous workspace versions are backed up.
Click Storage at the bottom to see the folder or download a complete backup.
Keep a backup on another disk for protection against device loss.

MOVE OLDER BROWSER SAVES
In the original app tab: Storage > Download workspace backup.
In the installed app: Storage > Import workspace transfer, then Reload imported
workspace. Imported tracks and packs are added; existing work is kept.
If the older version has no Storage button, export and import individual track
and custom-pack JSON files using its existing buttons instead.

PDF EXPORT
Choose Export to PDF, select Portrait or Landscape, then Download PDF.
The file is generated in the app; no browser print dialog is needed.

UPDATE
Choose Storage > Stop local app in the old copy and close that tab.
Download the newest release, extract it, then run its installer again.
Do not delete the saved data folder.

TROUBLESHOOTING
If the browser does not open, run the installed Start SlotForge launcher again.
If the footer says Storage: browser, open the installed launcher rather than HTML.
If it says saving failed, export your work as JSON before reloading.

More installation, storage, recovery and developer details: installer/README.txt.
Project and releases: https://github.com/theDutchmanJames/SlotForgeTrackBuilder

ADDITIONAL TRACK SYSTEMS
AFX Racing / Tomy (HO / 1:64), Carrera GO!!! (1:43), Carrera Hybrid
(1:50, slotless references) and Fleischmann Auto-Rallye (1:32) are included.
Choose them in the Track pack selector. Hybrid and unmeasured special pieces
use reference placement only; no guide slots or lane lengths are invented.
All physical dimensions remain millimetres, independent of model scale.
Modern Tomy/AFX does not imply compatibility with vintage Aurora A/FX.

WINDOWS STARTUP HELP
The desktop shortcut should open your default browser without a terminal.
If Windows cannot open the browser, the error dialog gives a local address
you can open yourself. Startup details: data/launcher.log in the installed
folder. Re-run the latest installer to repair a shortcut; data/ is kept.
