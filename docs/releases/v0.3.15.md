Design a routed circuit freely: draw one lane, generate the others, and plan how it fits your table.

## What's new

- **FreeForm Drawing** has its own page. Draw and reshape a continuous lane with smooth curve handles, close the loop, then generate up to eight lanes. Choose which lane your original drawing becomes, including a middle lane.
- **Clearer FreeForm tools:** Points, Lanes, Table and Checks tabs, with expandable folders matching Track Builder. Position, handles, height and squeeze tools sit together. Status and errors remain visible while scrolling; keyboard navigation works throughout.
- **L-shaped tables:** choose the removed corner and its dimensions. The actual table shape is included in fit checks, saved designs and PDF/SVG/DXF exports.
- **Smooth squeeze on straights and bends:** in FreeForm, select the start point, open Squeeze next stretch, set the tightest spacing and apply. The other lanes narrow toward the midpoint and widen again; your drawn lane stays fixed.
- **Heights and bridges across track types:** set surface heights, deck thickness and required clearance in the 2D editor. FreeForm figure eights can cross when there is sufficient height separation. New FreeForm drawings start with one lane; existing designs retain their settings.

Save FreeForm drawings to the builder, then choose **Save to Library**. Unfinished drafts remain editable; valid closed loops support Live Preview and route exports.

## Fixes and checks

The review fixed table-edge checks for single lanes, editing and export of distant/rotated/reflected FreeForm layouts, height matching at snapped ends and generated closing sections, proportional L-table resizing, imported reflection settings, failed-edit Undo/Redo handling, and repeated keyboard point movement.

**364 source tests**, **143 tests from the extracted Timing handoff**, and **15 integration fixtures** pass. Browser checks covered the new menu in light/dark themes, nested folders, keyboard controls, squeeze validation, heights, Undo/Redo, tables, saving and reopening.

## Compatibility and limits

The main `slotforge.layout` envelope remains **version 1**. FreeForm uses **1.0.0-draft.8**, height designs use **draft.9**, and shaped tables or FreeForm squeezes use **draft.10**. Older layout types retain their supported contracts.

**SlotForge Timing must adopt the matching shared runtime and contracts before importing these new layouts.** The developer handoff includes the specifications, runtime, examples and tests. No SlotForge Timing repository changes are part of this release.

Heights are planning checks in 2D. Lengths and CAD remain plan-view values; this release does not provide 3D ramp engineering, support design or car-body clearance validation. Native macOS/Linux installation and the separate Timing importer were not freshly audited for this release.

## Install or update

1. Download **SlotForge-Circuit-v0.3.15-complete.zip** and extract it completely.
2. If your installed app is running, click **Storage: disk** in the **bottom-right corner**, choose **Stop local app**, then close that tab. If saving has failed, download a workspace backup first.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"`, then start SlotForge Circuit again.

The installer retains your saved Track Library and custom packs. Direct HTML use continues to use browser storage.

Choose the **Complete ZIP** to install the app. The **Source ZIP** and **Timing handoff ZIP** are for developers. Each ZIP has a SHA-256 checksum. Personal workspaces and development screenshots are excluded.
