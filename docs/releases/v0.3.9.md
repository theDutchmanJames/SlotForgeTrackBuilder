SlotForge Track Builder is now **SlotForge Circuit**. This release adds routed wood track design, reusable routed sections, tabletop routing and construction exports for CAD and drawing software.

## What's new

- **Routed Tracks:** design straights, circular corners and flowing curves with draggable handles, exact coordinates, direction controls and a tool to bridge open ends.
- **Individual pieces or tabletop routing:** choose how each section will be built. Tabletop mode checks edge clearance against the real table boundary instead of an imaginary piece outline.
- **Your own routed packs:** save reusable sections to named packs, with matching artwork, or save and place them together. Converting a circular corner to a flowing curve preserves its angle, lane order and edge clearances.
- **Planning feedback:** check slot radii, open ends, overlaps and table clearances; see calculated lane lengths, material estimates, live previews and PDF reports.
- **SVG and DXF exports:** choose slot centrelines, slot edges, conductor edges, surface contours and table outlines as separate layers. Circular paths retain arcs; continuous matching paths are joined.
- **Compact SVG:** use automatic sizing or a fixed scale such as 1:10 or 1:50. The dialog shows the dimensions and enlargement needed to restore full size. DXF always stays at 1:1 in millimetres.
- **CAD import repairs:** complete DXF document tables and plot-style references fix the reproduced Illustrator memory error and Fusion insertion failure. The corrected drawing was imported successfully in both applications.
- **Reliability improvements:** repairs to routed geometry checks, export size, saved packs, PDF reporting and circular-to-flowing conversion, plus faster checks for larger flowing layouts.

## Install or update

1. Download **SlotForge-Circuit-v0.3.9-complete.zip** and extract it completely.
2. If the installed app is running, click **Storage: disk** in the **bottom-right corner**, choose **Stop local app**, then close that tab. If saving has failed, download a workspace backup first.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"` for your system.
4. Start **SlotForge Circuit** using its shortcut or the installed **Start SlotForge** launcher.

Your Track Library and custom packs are retained. Existing Track Builder launchers still work; the installation and data folders deliberately keep their original name. Direct HTML use still uses browser storage rather than disk storage.

## Validation and compatibility

**281 source tests pass**, along with **68 standalone Timing handoff tests** and **all 15 legacy integration fixtures**. The reported DXF was checked in Autodesk Fusion and Adobe Illustrator 2021; the compact SVG was also opened in Illustrator. Independent checks confirmed that the repair preserved all original vertices and arc values.

The main layout envelope remains version 1. Timing importers must explicitly support **draft.3** for circular/straight routed tracks, **draft.4** for flowing curves, and **draft.5** for tabletop routing. Ordinary layouts retain draft.2. This release includes the receiving-side handoff; it does not update SlotForge Timing itself.

Construction exports contain geometry, not CNC toolpaths. Dimensions and 2D checks remain planning aids. Windows has been tested; native macOS/Linux installer testing remains outstanding. The package remains unsigned and uses the existing source-available license permitting free personal, club and internal business use, with resale and paid access restricted.
