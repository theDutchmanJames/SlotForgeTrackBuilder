Build visual layouts with reference pieces, including Carrera Hybrid, even when their exact geometry is incomplete. This release includes the reference-planning features developed in v0.3.5 and three fixes found during their code review.

## New: build with reference pieces

- **Carrera Hybrid is ready to plan.** Click its road pieces to add them, then drag and magnetically connect their approximate ends. Separate left/right parts retain their own artwork.
- **Configure other references.** Enable approximate snapping and choose a straight or curved planning shape, with editable width, length, radius and angle. Published partial dimensions are prefilled where available.
- **Mix compatible pieces.** Reference pieces can align with measured roads of the same track family and road width.
- **Save and share the layout.** The Track Library and PDF/PNG/CSV exports retain the drawing and piece quantities. The catalogue's **Ready to place only** filter includes pieces with planning presets.

Planning magnets align estimated drawing surfaces. They do not validate physical fit or create guide slots, measured lap lengths or slot-car simulation. Unknown lengths are clearly labelled.

## Reference editor fixes

- **Artwork follows edited geometry.** Changing a reference road's angle, radius, width or shape reshapes its picture so the visible road ends stay aligned with the magnets. Colours, markings, handedness and transparent edges are retained. Unchanged pictures stay untouched.
- **Cancel really cancels.** Closing or cancelling a reference dialog while its image loads cannot add a piece later. Stale requests cannot close or change the controls of a newer dialog.
- **References without pictures stay editable.** Valid imports without optional artwork use a selectable fallback drawing and retain their colour and reflection restrictions.

## Install or update

1. Download **SlotForge-Track-Builder-v0.3.6-complete.zip** and extract it completely.
2. If updating a running installed copy, click **Storage: disk** in the **bottom-right corner of the app**, in the footer. Choose **Stop local app**, then close that tab. If saving has failed, choose **Download workspace backup** before reloading or updating.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"` for your system.
4. Reopen the app using its installed shortcut or **Start SlotForge** launcher.

If the footer reads **Storage: browser**, you opened the HTML directly. There is no local helper to stop, so skip that step.

Updates preserve your saved Track Library and custom packs. The complete package includes all ten built-in packs, source code and installers. A `.sha256` checksum file accompanies the download.

## Validation and compatibility

**170 automated tests and all 15 Timing integration fixtures pass.** Browser checks verified a complete Hybrid visual layout, real drag-away/reattachment, reference-to-measured-road snapping, library save/reload, adjustable SCX references and PDF piece counts. The three editor repairs were also checked in the browser with a held image response, a picture-free reference and a 60° curve edited to 90°.

The package passed installation, reinstall, data-preservation and launcher checks. The existing Windows installation was updated with its saved workspace verified unchanged. Native macOS/Linux installation and desktop launch still need testing on those systems.

The `slotforge.layout` envelope remains **version 1**, and the Timing integration contract remains **1.0.0-draft.2**. Reference planning hints remain separate from slot routes. No SlotForge Timing repository changes are included.
