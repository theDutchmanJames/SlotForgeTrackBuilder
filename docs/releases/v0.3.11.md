Close a routed wood circuit in two ways, with an adjustable preview before applying.

## What's new

- **Fill closing gap…** finds the two open ends and creates a connecting section. Save it to a reusable pack and close the loop together.
- **Reshape to close…** adjusts a selected section at either open end. All other sections stay in place, and the saved pack definition stays unchanged.
- Both tools keep endpoints and directions fixed while letting you adjust the curve handles. They preserve lane alignment, reject folded geometry, and support Cancel, Undo and Redo.
- **Bridge selected ends…** remains available when your layout still has several gaps.

Select **Routed wood**, or your own routed pack, in the builder to find the tools. Automatic closure requires one connected routed track with exactly two open ends. It works for individual wooden pieces and tabletop routing; manufactured pieces are not stretched. Some gaps need manual layout adjustments because one valid flowing curve cannot connect them. Check the table-fit, overlap and preferred-radius feedback after applying.

## Install or update

1. Download **SlotForge-Circuit-v0.3.11-complete.zip** and extract it completely.
2. If your installed app is running, click **Storage: disk** in the **bottom-right corner**, choose **Stop local app**, then close that tab. If saving has failed, download a workspace backup first.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"`, then start SlotForge Circuit again.

Your saved Track Library and custom packs are retained. Direct HTML use continues to use browser storage.
