Four more track systems, matching vector artwork, and a repaired Windows desktop launcher. Build your layout in your browser and keep your saved tracks and custom packs on your computer.

## New track packs

- **AFX Racing / Tomy — HO / 1:64:** 17 drawings, including 10 nominal flat-road models. This is the modern Tomy/AFX connector family; vintage Aurora A/FX is outside this first pack.
- **Carrera GO!!! — 1:43:** 19 drawings, including 7 nominal flat-road models.
- **Fleischmann Auto-Rallye — 1:32:** 15 historic drawings, including 6 nominal flat-road models. The assumed 90 mm slot spacing is clearly labelled.
- **Carrera Hybrid — 1:50:** 11 slotless reference drawings with separate left/right parts. Reference placement is available; slot routes, snapping, calculated lane lengths and driving preview are not supplied.

All physical dimensions stay in millimetres. Model scale never resizes the road, and different track systems keep separate connector families. Sources and measurement gaps are documented in each pack.

## Launcher fixes

- Windows desktop shortcuts start the private helper without a terminal flash and open the default browser through Windows' normal URL handler.
- Startup errors are logged in `data/launcher.log`; Windows also shows an error dialog instead of failing silently.
- Repeated macOS/Linux launches preserve existing logs. Shell launchers check the private runtime and show where to find diagnostics.
- Linux shortcuts handle special characters in installation paths. A browser opener that stays running is no longer treated as a timeout failure.

## Install or update

1. Download **SlotForge-Track-Builder-v0.3.2-complete.zip** and extract it completely.
2. If updating a running installed copy, choose **Storage → Stop local app** in that copy first.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"` for your system.
4. Use the installed **SlotForge Track Builder** shortcut or **Start SlotForge** launcher next time.

The installer keeps your existing data folder. First-time setup needs internet to obtain the verified private Node.js runtime; no manual Node.js or npm installation is needed. After setup, the app works offline. Keep independent backups of your saved work.
