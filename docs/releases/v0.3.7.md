SlotForge Track Builder now has a light theme matching SlotForge Timing, with a clearly labelled **Light / Dark** switch in the top-right corner.

## What's new

- **Choose Light or Dark from the header.** The switch stays visible throughout the builder and Track Pack galleries.
- **A matching SlotForge style.** Light mode uses warm grey backgrounds, white panels, dark text and red accents, with matching buttons, fields and dialogs.
- **A clear drawing canvas.** The grid, selection, space guide and status labels adjust to the theme. Physical track artwork keeps its original colours.
- **Your choice is remembered.** The selected theme survives reloads and navigation between the app and galleries. Direct HTML navigation also carries the choice between pages.

## Install or update

1. Download **SlotForge-Track-Builder-v0.3.7-complete.zip** and extract it completely.
2. If the installed app is running, click **Storage: disk** in its **bottom-right corner**, then choose **Stop local app** and close the tab. If saving has failed, download a workspace backup first.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"` for your system.
4. Reopen SlotForge Track Builder using its shortcut or **Start SlotForge** launcher.

If you open the HTML file directly and the footer reads **Storage: browser**, there is no local helper to stop.

Updates preserve your saved tracks and custom packs. The complete ZIP includes the app, all ten built-in track packs, source code, installers and the project license. A SHA-256 checksum accompanies the download.

## Validation

All **170 existing automated tests** and **15 Timing integration fixtures** pass. Browser checks verified both themes, reload persistence, navigation to the pack library and a manufacturer gallery, and the custom-piece dialog. Shared theme controls and asset paths were checked on all 12 editor/catalogue pages.

The theme was visually checked through localhost. Direct `file://` navigation and native macOS/Linux installation were not visually retested for this release.

The `slotforge.layout` envelope remains **version 1** and the Timing integration contract remains **1.0.0-draft.2**. This update makes no SlotForge Timing repository changes.
