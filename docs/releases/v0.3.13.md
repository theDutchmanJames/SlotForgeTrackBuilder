Add a squeeze to routed wood sections: narrow the lanes inside a corner, then smoothly return to normal spacing at both ends.

## What's new

- Select a routed section and choose **Squeeze…** in the Selection panel, or enable **Lane squeeze** while creating a section.
- Set the narrower spacing, such as **100 → 80 → 100 mm**, and the transition length at each end.
- Keep the bundle centre or a chosen lane in place. End connections retain their original spacing.
- Preview the new paths and radii, save reusable squeezed sections to a pack, and use **Reset squeeze** or Undo when needed.
- Lane lengths, material estimates, PDF drawings and SVG/DXF exports follow the squeezed geometry. Conductors retain their entered width along each slot.
- The editor rejects folds, self-intersections and overlapping conductor footprints. Preferred minimum-radius feedback remains advisory; check car-body clearance separately.
- The preview stays visible while scrolling through the section controls. The Track Pack Library recognizes saved packs containing squeezes.

Circular corners become editable flowing approximations when squeezed. **Reset squeeze** restores uniform spacing along that flowing path; Undo can restore the original circular section after applying a change.

## Compatibility

The main layout format remains `slotforge.layout` version 1. Squeezed layouts explicitly use integration contract **1.0.0-draft.6**; **SlotForge Timing needs the updated shared runtime before importing them**. Earlier layout types retain their existing contracts.

Exported packs containing squeezes use custom-pack version 2, and saved custom libraries containing them use version 3. Earlier Circuit versions cannot read those new formats. Packs without squeezes retain their previous format versions. The Timing handoff includes the updated runtime, specification and regression tests; no Timing repository files were changed.

## Install or update

1. Download **SlotForge-Circuit-v0.3.13-complete.zip** and extract it completely.
2. If your installed app is running, click **Storage: disk** in the **bottom-right corner**, choose **Stop local app**, then close that tab. If saving has failed, download a workspace backup first.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"`, then start SlotForge Circuit again.

Your saved Track Library and custom packs are retained. Direct HTML use continues to use browser storage.
