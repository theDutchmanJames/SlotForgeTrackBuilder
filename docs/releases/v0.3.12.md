More room to browse routed wood sections. The left sidebar now gives the catalogue most of its space instead of stacking every routed tool above it.

## What's changed

- **Routed tools** sits beside the **Sections** heading. Open it for setup, loop-closing tools and display options.
- The menu opens over the catalogue without shrinking it. Choosing an action, clicking outside or pressing Escape dismisses it. Escape keeps your selected section selected.
- **＋ Section**, search and **Mirror new pieces** remain directly accessible.
- The README explains where to find the tools. The FreeForm concept plan is saved as parked documentation; FreeForm Drawing is not implemented in this release.

## Install or update

1. Download **SlotForge-Circuit-v0.3.12-complete.zip** and extract it completely.
2. If your installed app is running, click **Storage: disk** in the **bottom-right corner**, choose **Stop local app**, then close that tab. If saving has failed, download a workspace backup first.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"`, then start SlotForge Circuit again.

Your saved Track Library and custom packs are retained. Direct HTML use continues to use browser storage.
