This release repairs nine issues found during an in-depth review, with a focus on protecting saved work, preserving custom-piece measurements and making exports match the editor.

## Fixes

- **Protect newer saved tracks.** An older editor window can no longer silently overwrite a newer library version. Reopen the saved track or keep your edits as a new copy. This works with disk storage and the browser library, and remembers the opened revision after reloading.
- **Keep unsaved work visible.** Closing or reloading warns about pending or failed saves. Stopping the local app waits for queued saves and keeps the helper running if autosave fails. Use **Storage → Download workspace backup** to keep a portable copy.
- **Match exported pictures to the editor.** PNG exports retain road markings, curbs, border colours and starting grids through the same drawing code used by the editor and PDF report. PNG backgrounds remain transparent.
- **Preserve imported custom pieces.** **Copy & adjust** keeps imported connector families and uneven slot positions. Switching to uniform slot spacing is explicit, and copying a maximum-length piece name stays within the limit.
- **Recover interrupted saves.** Abandoned partial write-lock files can recover after a safety grace period, while fresh locks and locks held by live processes remain protected.
- **Keep custom pack labels consistent.** Renaming a pack updates the pack name in its member pieces.
- **Allow export retries.** Export controls recover after a failed action.
- **Reject malformed piece metadata.** Invalid connector families and reflection flags fail validation instead of silently changing compatibility.
- **Import long track names safely.** An imported copy reserves room for its name suffix when a design identity already exists.

## Install or update

1. Download **SlotForge-Track-Builder-v0.3.4-complete.zip** and extract it completely.
2. If updating a running installed copy, click **Storage: disk** in the **bottom-right corner of the app**, in the footer. Choose **Stop local app**, then close that tab. If saving has failed, choose **Download workspace backup** in this panel before reloading or updating.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"` for your system.
4. Reopen the app using its installed shortcut or **Start SlotForge** launcher.

If the footer button reads **Storage: browser**, you opened the HTML directly. There is no local helper to stop, so skip that step.

Updates keep your saved Track Library and custom packs. The package includes all ten built-in packs, source code and installers. The `.sha256` file lets you check the download.

## Validation and compatibility

**148 automated tests pass, including 15 new regression tests. All 15 Timing integration fixtures pass.** Catalogue validators, 57 JavaScript syntax checks and 981 local link/asset checks pass too.

Isolated browser checks verified stale-window conflict recovery, disk save/reload, custom-piece copying and pack renaming, group selection, borders, undo/redo and live preview. Actual PDF and transparent PNG downloads were checked; the portrait PDF was rendered for visual inspection. Package installation, reinstall, launch and data preservation passed. The existing Windows installation was updated with its saved workspace verified unchanged.

Native macOS/Linux installation and desktop launch still need testing on those systems. See [the full review](https://github.com/theDutchmanJames/SlotForgeTrackBuilder/blob/v0.3.4/app/REVIEW.txt) for scope and remaining limits.

The `slotforge.layout` envelope remains **version 1**, and the SlotForge Timing integration contract remains **1.0.0-draft.2**. Receiving runtimes should update `core.js` and `integration.js` together because picture rendering now shares `Forge.drawBody`. No SlotForge Timing repository changes are included.
