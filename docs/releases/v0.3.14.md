Smooth the lane squeeze through a routed corner, with the narrowest spacing only at the apex.

## What's changed

- **Smooth apex** gradually narrows the lanes through the whole section, then widens them again toward the exit. This removes the short entrance and exit ramps around a constant-width middle.
- New squeezes default to **Smooth apex**. Existing squeezes keep their original **Hold narrow spacing** shape until you choose to change them.
- To update an existing corner: select it, open **Squeeze…**, choose **Squeeze shape → Smooth apex**, then click **Update section**.
- The original spacing, slot directions and curvature are preserved at both ends. You can still anchor the bundle centre or a chosen lane.
- Saved packs, layout files, lengths, material estimates and exports preserve the selected squeeze shape.

The apex is the midpoint along the reference path of this individual section. Separate sections are not automatically combined into one corner. Circular-to-flowing conversion remains an approximation, and car-body clearance still needs checking.

## Compatibility

Smooth apex uses integration contract **1.0.0-draft.7**, with version-2 squeeze parameters. **SlotForge Timing needs the updated shared runtime before importing Smooth apex layouts.** The main `slotforge.layout` envelope remains version 1.

Existing Hold narrow spacing squeezes retain their geometry and draft.6 contract. Older layout types and supported imports remain compatible. The Timing handoff includes the updated runtime, specification and tests; no Timing repository files were changed.

## Install or update

1. Download **SlotForge-Circuit-v0.3.14-complete.zip** and extract it completely.
2. If your installed app is running, click **Storage: disk** in the **bottom-right corner**, choose **Stop local app**, then close that tab. If saving has failed, download a workspace backup first.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"`, then start SlotForge Circuit again.

Your saved Track Library and custom packs are retained. Direct HTML use continues to use browser storage.
