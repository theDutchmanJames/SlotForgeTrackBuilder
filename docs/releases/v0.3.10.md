This small update fixes **Plugins → Routed Wood → Browse pack**. It now opens the Routed Tracks page instead of the broken `/app/undefined` address, including after changing the routed profile.

## Install or update

1. Download **SlotForge-Circuit-v0.3.10-complete.zip** and extract it completely.
2. If your installed app is running, click **Storage: disk** in the **bottom-right corner**, choose **Stop local app**, then close that tab. If saving has failed, download a workspace backup first.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"` for your system, then start SlotForge Circuit again.

Your saved Track Library and custom packs are retained. Direct HTML use continues to use browser storage.
