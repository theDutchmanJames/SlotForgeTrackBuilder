Make SlotForge Track Builder your own with **Settings → App Theme**, matching SlotForge Timing's preset and custom colour themes.

## What's new

- **Eight ready-made themes:** Dark, Light, Midnight blue, Forest green, Sunset orange, Violet, Carbon and yellow, and Ocean (light).
- **Your own colours:** choose the background, panels, text, quiet text, lines and accent. Changes appear immediately throughout the editor and galleries.
- **Start with a preset:** copy any theme, then adjust it. Trying other themes keeps your custom palette available.
- **Readability feedback:** button text adapts to the accent colour, and contrast warnings help you spot colours that may be difficult to read.
- **Easy access:** Settings is in the top-right header, beside the quick Light / Dark switch, including on every Track Pack gallery.

Theme choices are remembered in this browser. They are separate from your saved track files; another browser can have its own appearance. Track artwork keeps its physical colours and PDF reports stay printer-friendly.

## Install or update

1. Download **SlotForge-Track-Builder-v0.3.8-complete.zip** and extract it completely.
2. If the installed app is running, click **Storage: disk** in the **bottom-right corner**, choose **Stop local app**, and close that tab. If saving has failed, download a workspace backup first.
3. Run **Install Windows.cmd**, **Install macOS.command**, or `sh "Install Linux.sh"` for your system.
4. Reopen the app using its shortcut or **Start SlotForge** launcher.

If you opened the HTML file directly and the footer reads **Storage: browser**, there is no local helper to stop.

Updates preserve your saved Track Library and custom packs. The complete ZIP includes all ten built-in packs, source code, installers and the project license. A SHA-256 checksum accompanies the download.

## Validation and compatibility

**175 automated tests and all 15 Timing integration fixtures pass.** This includes five focused checks for preference migration, palette validation, custom-colour retention, portable HTML links and contrast feedback. Browser checks covered preset selection, custom editing, reloads, gallery navigation, copying a preset and contrast warnings.

Visual checks used localhost. Direct HTML navigation was covered by palette/link checks but was not visually tested. Native macOS/Linux installation remains to be tested on those systems.

The `slotforge.layout` envelope remains **version 1**, and the Timing integration contract remains **1.0.0-draft.2**. No SlotForge Timing repository changes are included.
