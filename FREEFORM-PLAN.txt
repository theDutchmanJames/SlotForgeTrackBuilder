CURRENT BASELINE AND DIRECTION
SlotForge Circuit v0.3.14 includes routed Bezier sections, tabletop routing,
direct handle editing, closed-loop tools, PDF/SVG/DXF, and both plateau and
Smooth apex squeezes. Reuse their geometry, rendering and export foundations.
FreeForm adds a whole-circuit authoring model; the existing section tools are
not a substitute for drawing and editing one continuous reference slot.

The proposed first release delivers a complete loop workflow: draw, edit,
generate lanes, check, save/reopen, animate and export. Local spacing comes
after that baseline. The detailed design below records the intended behaviour and delivery order;
app/FREEFORM-TOOLS.txt records the current controls and implementation limits.

PURPOSE
Offer FreeForm Drawing under Routed Tracks as an alternative to assembling
sections. Draw and edit a whole routed circuit on a table, then generate its
lanes. The user experiences one continuous circuit, although internally it can
consist of connected curve segments. Keep existing section-based tools.
This is for routed wood; manufactured track keeps its fixed physical geometry.

PROPOSED WORKFLOW
1. Set table dimensions or use an existing table guide.
2. Enter FreeForm Drawing and draw a reference slot centreline.
3. Close the reference path, then choose lane count, reference lane number,
   spacing and numbering orientation. Preview all generated lanes.
4. Edit points and handles directly on the canvas; linked lanes update together.
5. Review geometry checks, save to Track Library, preview and export.

DRAWING THE REFERENCE PATH
- Click to place a point; click and drag to place a point with curve handles.
  Default to assisted smooth points, with visible handles when selected.
  Users can explicitly straighten a stretch; they should not need to understand
  Bezier mathematics just to draw a usable bend.
- Preview the next segment as the pointer moves.
- Support straight segments and cubic Bezier curves: start/end anchors and
  two control handles. Curves can sweep, tighten, open out or form S-bends.
- Favour smooth joins. A Smooth point option can generate sensible handles
  for users unfamiliar with Bezier editing; sharp direction changes are flagged.
- Click the starting point or choose Close loop to finish. A coincident start
  and end is not sufficient: check the closing join's direction too.
- Initial toolbar: Draw, Edit points, Insert point, Delete point, Close loop,
  Generate lanes. Escape cancels the current gesture; Space+drag pans.
  Double-click finishes an open draft without pretending it is a closed track.
  Do not place a duplicate final anchor when finishing.

REFERENCE LANE AND LANE GENERATION - ACCEPTED CONCEPT
The drawn path need not be Lane 1. In Generate lanes, offer:
- Total lanes.
- Drawn path becomes: Lane 1 through the chosen total.
- Slot-centre spacing in millimetres.
- Reverse lane numbering, with numbered labels on the live preview.
- Display: slots only, or slots and braid/conductors.

Keep the drawn reference path exactly where the user put it. Generate the
remaining lanes on the appropriate sides, using normal offsets, not scaled
copies. Example: six lanes, drawn path assigned Lane 3, spacing 100 mm:
  Lane 1: -200 mm
  Lane 2: -100 mm
  Lane 3:    0 mm (drawn reference)
  Lane 4: +100 mm
  Lane 5: +200 mm
  Lane 6: +300 mm
General rule: signed offset = (lane number - reference lane number) * spacing,
with orientation determining which physical side is positive.
Changing reference lane assignment regenerates offsets around the unchanged
drawn path and reruns checks. Numbered previews must make the resulting order
unambiguous through S-bends, where inside/outside changes.
The earlier inside/outside placement idea is superseded by reference-lane
assignment and explicit numbering orientation.
PROPOSED NUMBERING CONTROLS
Separate two actions that would otherwise be confused:
- Higher lane numbers: left/right of the drawing direction. This controls the
  physical side of generated offsets. Preview the changed footprint before
  applying it; the drawn reference slot stays fixed.
- Reverse numbering: relabel the existing physical paths without moving them.
  The reference-lane number becomes totalLanes + 1 - oldReferenceLaneNumber.
  Update the numbering-side setting at the same time so regeneration retains
  the same paths. Show the resulting reference-lane number immediately.

Drawing direction is shown by an arrow. Racing direction is separate and can
be reversed without moving slots, reversing numbering or changing lane IDs.
Numbered labels in the lane preview make these operations visible.

DIRECT CANVAS EDITING
- Drag anchors and handles; all generated lanes remain linked and update live.
- Smooth join: align neighbouring handles to avoid sudden direction changes.
- Straighten segment.
- Insert a point without changing the existing curve shape.
- Delete a point with a predictable preview of the changed shape.
- Move multiple selected points together.
- Lock a point to protect completed parts of the design.
- Preserve Undo/Redo and cancelable edits.
- Place start/finish separately from the first drawing point.
- Save and reopen unfinished/open drafts. Export a drawing of an open draft
  with a clear status, but do not report it as a valid closed racing circuit.

CHECKS AND FEEDBACK
Show per-lane lengths while editing. Highlight:
- Slot/conductor pinching, folds and self-intersections.
- Corners tighter than the preferred minimum slot radius.
- Paths outside the table and insufficient table-edge clearance.
- An open loop or abrupt direction changes at joins.
Do not silently generate unusable inner offsets in a tight hairpin.
Preferred radius advice is distinct from invalid geometry. Table clearances,
vehicle clearance and construction feasibility are not guaranteed by a
smooth-looking path or a successful offset calculation.

LOCAL SPACING - LATER ITERATION
An explicit Local spacing tool could narrow/widen spacing through a selected
stretch, with gradual transitions into and out of it. This requires separate
checked lane paths, not constant offsets. Keep lanes linked to the design
rather than enabling accidental independent lane movement.
Transition editing, minimum separation and conductor checks need further design.
The existing section Squeeze and Smooth apex tools provide useful mathematics,
but FreeForm needs a selected stretch along the complete reference loop rather
than a squeeze restarting at each internal curve boundary. A stretch may cross
the closing seam. Keep its reference slot anchored by default, even when that
slot is Lane 3, and validate all generated paths globally.

SAVE, PREVIEW AND EXPORT
- Save the complete editable circuit to Track Library, including anchors,
  handles, reference-lane assignment, lane ordering and construction settings.
- Support Live Preview and the shared animation profile on generated slots.
- PDF: table, layout, lane lengths and construction/material information.
- SVG/DXF: accurate lane and conductor geometry with the existing scale rules.
- SlotForge Timing: export usable continuous lane routes, stable identities,
  start/finish offsets and driving direction. Verify receiving-side support;
  do not assume existing contracts accept a new editable FreeForm definition.
- Internal connected segments may reuse existing geometry infrastructure,
  but section boundaries should not dominate the drawing workflow.

SUGGESTED FIRST ITERATION
One closed reference path, straight/Bezier segments, constant lane spacing,
choice of which lane was drawn, explicit lane ordering, direct canvas editing,
clear geometry checks, persistence, Undo/Redo and compatible exports.
Defer local spacing variation and other advanced construction tools.

IMPLEMENTATION APPROACH - PROPOSED
- Add a dedicated FreeForm mode under Routed Tracks. Start on a continuous
  tabletop, with the existing rectangular table and construction profile.
  Keep the familiar canvas, themes, zoom and pan. Do not require catalogue
  pieces or show internal curve seams as separate boards.
- Store the authoring path as ordered, stable anchor IDs, positions, incoming
  and outgoing handle vectors, join modes and a closed/open flag. Persist
  the circuit ID, reference-slot identity, lane identities, spacing, numbering
  settings, construction profile and timing-line location with it.
- Generated slot samples are derived data. Regenerate them from the saved
  authoring path and settings; exporting only a picture or sampled paths
  would lose the ability to reopen and edit the design.
- Evaluate signed normal offsets directly from the drawn slot. The current
  routed-spline definition assumes a bundle-centred reference, so it cannot
  simply be reused unchanged when the drawn slot is an off-centre lane.
  Do not approximate that shift by moving/scaling cubic control points.
- Reuse the Bezier evaluator, sampling targets, slot-normal conductor edges
  and geometry diagnostics where appropriate. Validate joins and crossings
  over the complete loop, including the closing seam and different spans.
  Individually valid curve segments do not prove a valid whole circuit.
- Inserting a point splits the cubic without changing the curve. Smooth joins
  require matching tangents. Show curvature jumps separately; aligned handles
  alone do not guarantee continuous curvature or sensible offsets.
- Retain an invalid drag as an editable preview with clear feedback. Cancel
  restores its pre-drag state. Never silently clamp a bad hairpin into a
  different design or overwrite the last good geometry with stale samples.
- Lane identities must survive point insertion, harmless anchor-list rotation,
  geometry edits and label-only reversal. The current Timing route hash uses
  section membership, so feeding each editable span through it unchanged
  would cause unnecessary remapping. Design a FreeForm-aware route identity
  using the circuit and persistent lane IDs. Changes in lane topology must
  still request an explicit mapping review in Timing.
- Timing-line position must survive splitting its containing curve. It is
  independent of the first anchor, and must be remapped deliberately if the
  containing stretch is deleted. Do not silently move start/finish to zero.
- Use a versioned authoring schema and an explicit integration-contract
  extension. Reserve the actual next contract at implementation time.
  Older readers must reject unsupported FreeForm data before normalizing it.
- Treat the first release as a dedicated FreeForm design type. Automatic
  conversion of arbitrary section layouts and mixing independent plastic or
  routed pieces into the same FreeForm circuit are later work. Existing
  designs continue to open in their current editor.

DELIVERY ORDER
1. Reference-path model and canvas tools: smooth drawing, handles, point
   insertion/deletion, loop closure, Undo/Redo and saved unfinished drafts.
2. Lane generation and whole-loop checks: 1-8 lanes, reference-lane selection,
   numbering/side semantics, numbered preview, lengths and table clearance.
3. Complete workflow: Track Library, material estimates, Live Preview,
   timing line/direction, PDF, SVG/DXF and the explicit Timing handoff.
The first user-facing release should complete all three, rather than present
an editable line that cannot be saved and used as a track.

FIRST-ITERATION ACCEPTANCE EXAMPLES
- Draw one slot on a table; make a closed, smooth oval and a more varied loop.
- Generate six lanes with the drawn slot as Lane 3: offsets are exactly
  -200, -100, 0, +100, +200, +300 mm at 100 mm spacing, subject to the
  selected generation side. The drawn slot does not move.
- Reverse numbering without moving any physical path. Explicitly flip the
  generation side and show the changed footprint before applying it.
- Drag a smooth anchor; linked lanes, lengths and feedback update together.
- Insert a point without moving the drawing or changing lane identities.
- Close a loop with an invalid tangent and show the exact failing join.
- Make a hairpin whose inner offsets fold; highlight the failing lanes and
  prevent a misleading usable-circuit export while preserving the draft.
- Detect overlaps between distant spans, not only within each cubic.
- Save/reopen the editable circuit, preserve timing references and Undo edits.
- Match full-size SVG/DXF, PDF and Live Preview to the same generated paths.

REMAINING DESIGN WORK
- Validate automatic smooth-handle behaviour with a small interaction prototype,
  especially during loop closure, after deleting a point and beside a straight.
- Finalize the authoring schema, shared runtime interface, validation limits,
  global intersection strategy and receiving-side contract revision.
- Confirm how invalid in-progress drafts are presented in reports and JSON
  without advertising usable racing routes or construction-ready geometry.
- Non-rectangular tables, elevated crossings, local spacing, automatic section
  conversion and manufacturing toolpaths remain outside the first iteration.
