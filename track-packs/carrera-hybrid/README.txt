Carrera Hybrid
Model scale: 1:50; slotless; physical units: mm.

Slotless black surfaces with red/white and blue/white edge strips, without metallic rails or guide slots. Standard straight: 433 × 250 mm; standard curve: 375 mm centre radius.

Use reference placement for visual planning. This first Hybrid pack intentionally provides no slot routes, lane lengths, snapping or slot-car preview. Red/blue edges distinguish left- and right-hand physical parts.

Measurement gaps:
- Hybrid is reference-only in this version of the slot-track editor. Reference placement is available, but snapping, centreline / per-lane lengths, slot preview and Timing slot routes are not supplied.
- Left and right are separate physical parts with directional red/blue edge markings. They are listed separately; reflecting artwork does not make the opposite physical part.
- Standard straight and standard curve envelope use manufacturer dimensions. R2 dimensions use the cited independent examination. Special surfaces / accessories have incomplete footprints and remain schematic.
