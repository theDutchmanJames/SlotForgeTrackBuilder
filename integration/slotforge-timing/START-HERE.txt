SlotForge Timing integration handoff — routed squeeze extension (v0.3.13)
31 October 2026

CURRENT CONTRACT
slotforge.layout envelope: version 1 (unchanged)
integration.contractVersion: draft.6 for squeezed lanes; otherwise draft.5 for tabletop routing, draft.4 for flowing curves, draft.3 for circular/straight routed, draft.2 otherwise
Supported imports: draft.6, draft.5, draft.4, draft.3, draft.2, draft.1, and documented legacy/unversioned v1.
Explicit unknown versions and unsupported units are rejected before normalization.
The app is now named SlotForge Circuit. New exports use that producer.name;
older SlotForge Track Builder exports retain full compatibility. The rename
does not change the layout envelope, integration contracts or route identity.
Reusable routed packs may include catalogueFlip as an editor-only preferred
reflection. Layouts already serialize explicit placement flips; no new route
geometry or integration-contract revision is introduced by pack saving or
the circular-to-flowing conversion fix.

MODULE ENTRY POINTS
 const I = require('./app/integration.js');
 const imported = I.importLayout(parsedJSON);
 const regenerated = I.prepare(parsedJSON, imported.state);
Enforce the 5 MiB external JSON limit before parsing. Derived geometry and
cached summaries are untrusted; regenerate them through the runtime.
Large portable exports may omit preparedGeometry. Embedded definitions are
sufficient: importLayout()/prepare() regenerate the slot paths and timing data.

EXAMPLES
routed-examples/closed-tabletop-track.slotforge.json is a compact draft.5
four-lane tabletop circuit. It omits derived geometry intentionally; the
runtime regenerates it from its definitions during import.
routed-examples/closed-flowing-track.slotforge.json is a draft.4 three-lane
flowing circuit with normal-offset paths, a timing cross-section and reversal.
routed-examples/closed-routed-oval.slotforge.json is a complete draft.3 routed
circuit with construction profile, table, lane geometry and timing line.
v1-fixtures/ contains the 15 existing compatibility/rejection cases, including
2/4/8 lanes, reflected/reversed routes, timing offsets and identity revisions.
v2-examples/closed-with-reference.slotforge.json is a draft.2 closed circuit
with a reference-picture placeholder (no image, illustrating the fallback).
References do not alter lane lengths, IDs or circuit closure.

Historical v0.1.3, v0.2.0 and v0.2.1 notes/fixtures remain where useful. Current
instructions in this file and CODEX-BRIEF-v0.2.2.txt supersede older handoffs.
No SlotForge Timing repository changes were made. The contract remains a draft
until Timing explicitly adopts and tests it.
